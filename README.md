# 📚 Awesome OpenClaw

> A curated list of awesome OpenClaw resources, skills, and tools.

[![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

OpenClaw is a powerful AI assistant framework that enables AI agents to interact with the real world through tools, skills, and plugins.

## 🎯 Official Resources

- [OpenClaw Docs](https://docs.openclaw.dev) - Official documentation
- [OpenClaw GitHub](https://github.com/openclaw/openclaw) - Source code
- [OpenClaw CLI Reference](https://docs.openclaw.dev/cli) - Command reference

## 🛠️ Tools & Plugins

### Core Tools
- `exec` - Run shell commands
- `read/write/edit` - File operations
- `message` - Send messages via channels
- `canvas` - Node canvas control
- `tts` - Text-to-speech

### Browser & Web
- [agent-browser](https://github.com/openclaw/agent-browser) - Headless browser automation
- [openclaw-browser](https://github.com/openclaw/openclaw-browser) - AI browser skill

## 💡 Tips

- Use `SOUL.md` to define your agent's personality
- Use `AGENTS.md` to set workspace rules
- Keep credentials in `TOOLS.md`, not in shared skills
- Use `MEMORY.md` for long-term context
- Group chats are public — treat them accordingly
